# 联网搜索

用 `web_search` 拿候选，需要某页细节再用 `web_fetch`。两者都直接返回 API 原始 JSON，字段含义见工具说明。

## 读结果

- `rerank_score` ≥ 1.5 才算优质，低于 1 通常不相关，优先取高分。
- `authority` ≥ 3 为高权威；`-1` 表示未知。
- 优先读 `summary`，不要无端开 `need_content`。
- `date` 是 UTC，换算后再表述；为 `null` 时不要把内容当"最新"。
- 同一结论在多个不相关站点出现才算交叉印证，转载同一稿不算。

## 表达

- 关键结论附来源 URL。
- 没查到就说没查到，不要用记忆填充冒充搜索结果。
- 页面无可用正文（登录墙、纯脚本渲染）时直接说明。
- 结果互相矛盾时指出分歧，不要挑一个当定论。
